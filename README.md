## Description
A multi-page website that shows how jQuery works: selectors, effects, DOM manipulation, animations and a mini project (Accordion Menu). jQuery 3.7.1 is loaded from a CDN. Every page has a navbar that links to all parts.

| Page | Script | Tasks |
| --- | --- | --- |
| `index.html` | `part1.js` | Task 0 (setup, `$(document).ready`), Task 1 (selectors, `.text()`, `.html()`, `.css()`) |
| `part2.html` | `part2.js` | Task 2 (`hide`, `show`, `toggle`), Task 3 (`fadeIn`, `fadeOut`, `fadeToggle`), Task 4 (`slideUp`, `slideDown`, `slideToggle`) |
| `part3.html` | `part3.js` | Task 5 (`append`, `prepend`, `remove`), Task 6 (`attr`), Task 7 (`val`, `text`) |
| `part4.html` | `part4.js` | Task 8 (`animate`), Task 9 (sequential animations), Task 10 (combined animation) |
| `part5.html` | `part5.js` | Task 11 (Accordion Menu with slide animations) |

1. Clone the repository or download the ZIP.

3. Open the console with F12 to see the message of Task 0.
