1. What is jQuery?
jQuery is a JavaScript library that makes it easier to select elements, handle events and create animations.
2. What are selectors?
Selectors find elements on the page. For example, $("#id"), $(".class") and $("p").
3. What are effects?
Effects show or hide elements: hide(), show(), fadeIn(), slideDown() and others.
4. What does animate() do?
The .animate() method smoothly changes numeric CSS properties, like width, height, left, top and opacity.
